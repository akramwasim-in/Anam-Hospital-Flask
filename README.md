# 🏥 Anam Hospital Management System (Flask Web App)

A lightweight and responsive Flask-based web application designed for **Anam Hospital**. 
This application handles the hospital's web presence, layout templates, and core backend routes.

---
## 🚀 Features
- **Dynamic Routing:** Built using Python Flask for seamless backend performance.
- **Responsive UI:** Custom CSS and modern styling for desktop views.
- **Template Inheritance:** Uses Jinja2 templates (`templates/index.html`) for clean HTML structure.
- **Static Asset Management:** Serves custom stylesheets and images via Flask's static folder.
- **Version Controlled:** Fully synced with Git & GitHub with automated deployment setup.

---
## 🛠️ Tech Stack
- **Backend:** Python (Flask Framework)
- **Frontend:** HTML5, CSS3, Font Awesome, Google Fonts
- **Database:** SQLite (`database.db`)
- **Version Control:** Git & GitHub
